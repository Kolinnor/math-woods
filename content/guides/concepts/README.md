# Concept contributor guide

The public guide at [/contributing/guides/concepts](https://mathwoods.org/contributing/guides/concepts)
is maintained here:

- [French guide](fr.md)
- [English guide](en.md)

To suggest wording or typography corrections, edit the relevant Markdown file
in a pull request. Keep its title and description metadata.
Do not manually edit `site-snapshot.json`: it records the site version used
to detect concurrent edits.

Administrators can also edit the guide on the website. Those changes are
merged into these files when a maintainer prepares the next deployment.
The reviewed files are then applied to the site during deployment.
See the [synchronization workflow](../../../docs/concept-guide-sync.md).
